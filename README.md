# Secure File Transfer

Проект для передачи файлов между клиентом и сервером с использованием криптографической защиты.

В приложении реализованы:
- сервер для хранения пользовательских файлов;
- клиент с графическим интерфейсом;
- консольный клиент для отладки и тестирования;
- генерация RSA-ключей на стороне клиента;
- передача симметричного ключа при подключении;
- шифрование данных с использованием AES;
- регистрация и авторизация пользователей;
- загрузка, просмотр списка, скачивание и удаление файлов;
- хранение данных сервера в SQLite.

## Структура проекта

- `server_app` - серверная часть, база данных, обработчики и криптография.
- `client_app` - клиентская часть, GUI и консольный интерфейс.
- `docker-compose.yml` - запуск сервера в Docker.
- `server.py` - точка входа сервера.
- `clientGUI.py` - основной запуск клиента с GUI.
- `client.py` - запуск клиента через командную строку.

## Основной сценарий работы

Основной способ работы с приложением - графический интерфейс клиента.

Через GUI можно:
- подключиться к серверу;
- зарегистрироваться или войти;
- загрузить файл;
- получить список файлов;
- скачать файл;
- удалить файл.

Консольный интерфейс также доступен и удобен для отладки, пошаговой проверки протокола и быстрого тестирования без GUI.

## Запуск сервера

Сервер запускается через Docker:

```powershell
docker compose up --build
```

После запуска сервер будет доступен на порту `9090`.

## Запуск клиента

Для запуска графического клиента:

```powershell
python clientGUI.py
```

Для запуска консольного клиента:

```powershell
python client.py
```

## Настройка

Параметры клиента задаются в `client_app/.env`.

Пример:

```env
CLIENT_HOST=127.0.0.1
CLIENT_PORT=9090
```

Параметры сервера задаются в `server_app/.env`.

Пример:

```env
SERVER_HOST=0.0.0.0
SERVER_PORT=9090
SERVER_DB_PATH=/data/bd.sqlite
```

Если клиент и сервер работают на разных устройствах в одной сети, в `CLIENT_HOST` нужно указать IP-адрес машины, на которой запущен сервер.

## Итог

Проект представляет собой готовое клиент-серверное приложение для защищённой передачи файлов. Основной упор сделан на удобную работу через GUI, при этом консольный режим сохраняется как полезный инструмент для отладки и демонстрации работы протокола.
